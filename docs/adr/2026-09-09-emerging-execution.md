# 興櫃日線執行價格與資金時序

日期：2026-09-09。決策範圍：使用者要求的含興櫃研究回測，不變更券商／Hetzner實盤。

## 問題與證據

FinMind的興櫃TaiwanStockPrice.open是前日均價，不是當日開盤；max/min是當日高低、close是最後成交。舊引擎直接用open成交及以open修補high，對興櫃不成立。官方说明 https://finmind.github.io/tutor/TaiwanMarket/Technical/ ，櫃買中心FAQ亦說明興櫃是推薦券商報價主導的議價市場，沒有集中市場開收盤價。

## 決策

1. 興櫃僅在官方已核實登錄／終止區間內使用，登錄日含、終止日不含。未知區間排除；轉板連接以實際日期為準。
2. 為日線研究使用訊號後下一市場交易日的VWAP（成交金額÷股數）作成交代理，訊號和預算必須已在前一天決定。資料無有效量值或均價落在真實高低範圍外，不能成交。訊號／估值維持最後成交價，open歸零，真正max不受前日均價污染。
3. 每邊額外滑價0/0.5%/1%作敏感度測試；原引擎每邊0.3%模型交易成本保持。每筆興櫃委託不得超過當日總股數1%，不模擬部分成交，超額買單取消、賣單延後重試。
4. 全天VWAP賣出所得必須在所有當日買單處理後才入現金與NAV。興櫃買單依預先順位鎖定預算，未成交預算日終釋放。當日最終均價或成交容量結果不能改變同日上午其他買單的可用資金。
5. 既有上市櫃開盤成交路徑預設行為保持，新增hook均可選；興櫃研究runner明示啟用。A基準須對帳原結果。
6. 少於200個可能有效交易日的候選，已由登錄／終止日期與市場日曆證明不可能過暖機，可以省略抓價；名單與上界數量留在輸出。此判斷不使用未來報酬或價格。

## 驗證與限制

測試含買賣方向滑價、容量邊界、資金預留與釋放、禁止日終賣款倒流、極端未來VWAP不改變上午買單、轉板及重新登錄間隙、獨立截斷原始行情與股票池重建、訊號／成交日期及200日條件。

這不是逐筆可成交證明，也不是收益下界。缺歷史買賣報價與委託深度，錯失交易後的價格路徑可能提高或降低最終收益；只用高流動性門檻、1%容量與滑價仍不能消除此不確定性。既有股利／公司行動與營收歷史修訂限制仍在。三组A/B/C使用同一營收快照與指標定義，C加入市場後的排名及資金路徑改變須與興櫃單筆損益分開解讀。
