# 歷史上市上櫃資格與研究暖機

狀態：採用。日期：2026-09-09。決策者：Codex，依使用者「僅限上市上櫃」要求。

## 背景

原候選聯集FinMind Info/Delisting，沒有歷史資格區間。7610上市日2025-09-09，卻有上市前成交；2026-02動能暖機也包含興櫃價。只改最終买入清單仍會讓興櫃價格影響排名分母、動能、均線與200日暖機。

## 決策

- 新`ListedUniverse`按官方有效start inclusive/end exclusive建立可交易區間。未知期間拒絕；不以Info更新日或首筆行情猜上市日。
- 本研究採嚴格暖機口徑：所有排名、動能、MA、委託執行都使用限定後行情；200日只計已核實上市／上櫃資料。這是明示研究設計，比僅限制成交日更嚴格。
- 創新板是TWSE上市；本輪不另改TDR資產類別。核實的上櫃轉上市區間可連續，但缺原上櫃起日不得回填。
- 從最早資料起套用有效區間，不從現在仍存續與否挑歷史候選。仍有未知歷史起日造成保守股票池偏誤，明列而不宣稱完整PIT。
- 有效資格終止不代表可用已知價格即時清算。沒有可執行行情時維持未解決部位、不補假現金；此問題不在本輪冒充已解決。
- 当前比較CLI預設限定，legacy需明示旗標。保留舊績效但加更正標記。上市區間raw、hash、coverage與回測指紋保留供重現。

## 後果

需重算整個排名／資金路徑，而非從舊交易刪幾筆。較新上市股票可能滿200日後還要等前月動能比較值可用才入選。嚴格範圍不能消除營收修訂、公司行動、存活偏誤與樣本反覆選參數限制；其績效仍為探索研究。
