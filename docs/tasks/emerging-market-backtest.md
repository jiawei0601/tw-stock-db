# 含興櫃的正式研究回測（2026-09-09）

使用者要求加入興櫃並正式回測收益。本次新增獨立報告，不覆蓋上市上櫃限定版，也不修改Hetzner或券商。

## 已確認的重要資料語意

FinMind TaiwanStockPrice 的興櫃 open 是前日均價，不是當日開盤價；close為當日最後成交，max/min為當日高低。來源 https://finmind.github.io/tutor/TaiwanMarket/Technical/ 。舊版直接用open成交以及把open納入high-envelope不能用於正式興櫃研究。

## 共用合約與驗收

- 主線負責 `emerging_market.py`、`compare_emerging_momentum.py`、本文件、相關測試與 `weekly_hermes_momentum.py` 的可選執行價格hook。
- `simulate_weekly(..., execution_price=None)` 保持預設結果不變；callback `(stock_id:str, day:str, row:dict, side:'buy'|'sell')->float` 僅於預先排定委託的成交日呼叫，非正或非有限價格拒絕成交。
- 興櫃採下一市場交易日VWAP（Trading_money/Trading_Volume），無交易、未知資格或VWAP不在當日高低範圍內則不得假造成交。另測每邊0.5%/1%滑價；這是日線成交代理，非可實現成交保證。訊號仍用當日最後成交價，買入预算只用前一訊號日NAV。
- 興櫃行情在指標輸入中open歸零，保留真正當日高低/最後成交；禁止前日均價抬高當日high。上市上櫃沿用原成交方法。
- 新可選 `execution_capacity(sid,day,row,side,shares)->bool` 於成交價格驗證後限制完整委託量。興櫃每筆不得超過當日股數1%；超額買單取消、超額賣單依既有pending後續重試，不假設一股成交量能承接整筆部位。不部分成交；上市櫃沿用原假設。1%為研究執行假設，非選股條件，需在報告揭露。
- 新可選 `sale_cash_at_close(sid,day)->bool` 延後VWAP賣出所得至當日所有買單處理後才入現金／NAV；全天均價所得不可以支付同日上午買單，避免執行層偷看未来。興櫃為True，上市上櫃沿用open所得時序。
- 新可選 `reserve_buy_cash_until_close(sid,day)->bool`：興櫃買單先依預排順位鎖定足額預算，若日終判定無法成交，直到日終才釋放。不能利用尚未知曉的當日成交量／VWAP失敗結果，把同一筆錢倒流到稍後順位的當日開盤買單。
- 必須按歷史市場資格區間，含登錄日／不含終止日；目前市場別/首次行情不當作登錄證據。需納入仍興櫃及曾終止股票，不只事後轉上市的贏家。
- A嚴格上市櫃、B上市櫃成交但可用已核實興櫃歷史、C允許已核實興櫃成交；其他動能3-1、三日均成交金額>1億、營收三個月金額遞增且YoY正、週三、5%NAV、30%回落規則保持。
- 正式研究會揭露資格/行情/營收涵蓋、總回報/年化/MDD/勝率/交易市場歸因、截斷不變測試；不冒充完整PIT認證。
