# 動能30%策略：50萬元實際帳戶規格

版本2026-09-08。此為使用者目前採用的策略，不是最佳化參數承諾。部署於Hetzner `/home/chang/tw-momentum30`，透過既有Hermes Telegram通知使用者，不連券商、不自動下單。

## 資金與成交

- 初始可用現金500,000元，起始策略帳戶無已回報持股。每筆新倉目標為訊號日帳戶淨值5%，目前25,000元，含成本。
- 不借款、不設檔數硬上限；按動能排序。現金不足一完整目標則停止新增。持股不強制再平衡，不重複加碼；整數股向下取整，保留剩餘現金。
- 使用者接受小幅取整及正常成交誤差。報告列目標預算與估算股數，高價股取整低於目標90%時標明差距（呈現提醒，不是新增選股門檻）。
- 週三收盤確認，下一交易日10:00由使用者自行執行；通常週四。市價及零股的成交價、時間、委託支援取決於券商，不保證等於回測的次日一般市場開盤價。
- 每筆實際成交以唯一ID、代號、買賣方向、整數股數、成交均價、實際手續費與稅合計、日期入帳。不將建議當成交。賣出回報後才增加帳本現金；待賣部位不提前釋出資金，因此週三候選可能比假設次日全部賣成的回測保守。

## 週三買進

1. 3−1動能＝上一月底收盤÷三個月前月底收盤−1（已知分割事件換算）。例如2026年9月採6月底到8月底，不是63／21日滾動。
2. 最近252個市場交易日至少200個有有效收盤與成交量的交易日；必要端點與訊號日有效。
3. 全部合格股票依動能排序，取前25%（向上取整），動能須大於0，且高於上個月的動能。
4. 再要求含週三當天最近3個市場交易日都有有效成交資料，平均實際成交金額嚴格大於1億元。未通過不從排名以外補足。
5. 排除既有持股，按動能高低（同分代號排序）配置。週三遇休市則當週不順延選股。

## 賣出

- 每日收盤追蹤買進後高點，收盤**嚴格低於高點70%**時，下一交易日10:00全數退出；恰好70%不觸發。訊號未實際執行前保留待賣，不因隔日反彈自動取消。
- 10:00買進當天不使用可能發生在買進前的日最高價：首日暫用成交均價與收盤的最大值作已知高點；其後採每日最高價。這是缺少分時資料下的明示差異，可能低估首日10:00後高點；若要精確首日追蹤需補分時或人工確認高點。
- 每月最後交易日另檢查：動能非正、連續兩次月度減弱、排名落出前40%、缺必要訊號。命中全數退出。同日停損及動能都命中，以高點停損為記錄原因。
- **沒有**原Hermes的90天觀察期、+20%晉升、MA20／60／120分批或成本10%停損。既有其他Hermes持倉SOP不套入本獨立帳戶。

## 資料與錯誤處理

- 本機FinMind截至9/7研究資料為暖機來源，取2024年9月以來足夠歷史。從9/8起使用TWSE `MI_INDEX`與TPEx `dailyQuotes`兩個官方全市場日期API增量更新，日曆使用TWSE年度開休市表。
- 回傳日期必須與請求相同、每市場至少500筆有效股票，OHLC需一致；任一必要日或市場失敗即通知資料警報，不發布舊買單。**實際通知不啟用回測用最高價猜值開關。** 每日原始回應留存。
- 歷史股票股利、現金股利與部分公司行動尚未完整處理。實盤公司行動也尚未自動對帳：已知分割或持有期異常跳空超过15%會停止該股自動判斷並要求核對。此偵測不是完整公司行動覆蓋，現金股利、小幅除權及減資仍須依券商紀錄人工核對帳本。不得宣稱已完整含息或無假性訊號。
- 缺持股行情／事件待核對時，停止新增買進股數，列明問題；不杜撰估值。所有結果仍需保留研究資料限制。
- `seed.json.gz`完整日更新成功後才原子替換；帳戶與報表分離、程序鎖避免並行入帳，成交ID重複拒絕。45天未更新需人工補資料。
