# 高點回落10%：價格路徑診斷回測

2026-09-08，Codex。使用者要求先跑回測。本次確實完成模擬，但屬 **PRICE_PATH_DIAGNOSTIC_ONLY**，不是已驗證投資績效。股票股利、現金股利與部分公司行動未完整入帳，歷史股票池完整性未認證；詳見 `momentum-2026-drawdown-audit.md`。

## 執行方式與資料假設

```powershell
python weekly_hermes_momentum.py --equity-allocation --momentum-exit --position-weight 0.05 --peak-stop 0.10 --diagnostic-high-envelope
```

原嚴格模式因6645／2020-07-02的開盤價147.2高於最高價147.0而停止。本輪明確啟用診斷開關：僅以同日開盤、最高、收盤三者最大值暫代矛盾最高價，原資料庫不修改。全載入資料共21,082筆改用此假設，均非最高價缺失；數量是全資料而非持倉期間筆數。這是高價下界假設，**不是經來源核實的修正**，也不能排除其他價格欄位本身有問題。

資料指紋：`d09d679783248191a2a857f6911c2eed8242ef8f1a85a76494734bfae4e59bf3`。

期間2020-01-02～2026-09-07，首筆買進2020-01-09；排除無交易資料的2026-07-10。2026為截至9月7日，非全年。

## 策略

- 初始100萬元，每筆新倉為週三訊號日淨值5%，含買入成本；無硬性檔數上限，現金不足一整筆則不買、不借款、不再平衡。
- 每週三收盤篩選，次交易日開盤交易；3−1動能採月底端點，正值且比上月增強，前25%後再要求近3交易日平均成交金額大於1億元。
- 月底動能非正、連續兩月減弱、排名落出前40%或缺必要訊號，次交易日出場。
- 持有後最高成交價只升不降，入場當日高價納入。每日收盤嚴格低於高點90%時，下一交易日開盤全出；不是盤中觸價成交。已知拆股同步換算高點與股數。
- 移動停損取代原成本停損；本版本無90天期限或Hermes均線分批。買賣各0.3%成本，採可分割股數近似。

## 驗證與限制

- 94項相關測試通過，包含高價單日處理不修改原始資料、未來高價不改變過去、拆股高點換算及嚴格10%邊界。
- 真實資料截斷於2022-12-30，訊號、過去淨值與賣出紀錄一致。這證明本輪程式的截斷一致性，不能證明上游歷史股票池／公司行動已具備完整時點性。
- 逐筆移動停損確認收盤低於高點90%、成交日嚴格晚於訊號日、全部全倉退出；買賣现金流及期末持股估值對帳誤差小於0.000001元。
- 22天有持股缺報價，以最後收盤價延用。改將當天缺報價持股估值設零，期末約163.17萬元、最大回撤55.19%；這只是敏感度情境，並非下市結算估計。
- 配股漏記可造成假性回落，污染停損、選股、持股數與後續配置。尚不能只將股利加回期末就視為修復，須補齊事件後重跑。
